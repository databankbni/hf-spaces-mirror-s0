# 주간 식단표 중복·충돌 검사기

매주 바뀌는 주간 식단표 엑셀(.xlsx)을 올리면, 여러 규칙 위반을 1차로 걸러 줍니다.
식단 데이터는 코드에 고정돼 있지 않고, 업로드한 내용만 검사합니다.

## 검사 규칙
1. 같은 날 국 종류 중복
2·3. 연속 끼니(전날 석식→다음날 조식 포함) 같은 메인 재료 반복
4. 생선 최소 3끼니 간격
5. 오리 주 1회
6. 순대 주 1회
7. 같은 버섯류 하루 중복
8. 순두부국 + 두부 반찬 중복
9. 국·반찬 메인 재료 중복
10. 같은 반찬 주재료가 정해진 끼니 수 안에 다시 나오면 안 됨 (재료별 기준)
    · 6끼니: 나물·계란(메란·메알=메추리알 포함)·두부·멸치·마늘쫑·어묵·감자·가지·고구마·옥수수(=콘)·미트볼·기성품전(해물완자전·동그랑땡·오색전)
    · 장조림은 **종류별로** 따로 셈 — 계란장조림(메란·메알·계란)과 돈육장조림은 서로 다른 메뉴
    · 5끼니: 소시지류(소시지·비엔나·후랑크)·연근·굴소스
    · 당근·양파·야채 같은 기본 채소는 겹쳐도 정상이라 검사에서 제외
11. 장조림류 주 2~3회
12. 잡채 주 1회
13. 카레 주 1회
14. 짜장 주 1회
15. 만두류(물만두·교자·만두) 주 1회
16. 튀김류(까스·튀김) 합쳐서 주 2회까지(3회 이상 금지)
17. 알탕·매운탕 합쳐서 주 1회
18. 묵류: (가) 종류 무관 5끼니 안 반복 금지, (나) 같은 종류 묵은 주 1회
    · 국(냉국)에 나와도 카운트, 여러 주 파일 올리면 주 경계도 이어서 봄
    · 어묵(생선살)은 묵류 아님
19. 기성 떡갈비류(너비아니·떡갈비·갈비경단·경단·산적) 같은 날·연이틀 금지(하루 걸러서만)
20. 쥐어채·명엽채 합쳐서 주 2회까지
21. 도라지 주 2회까지
22. 면류(국수·냉면·스파게티·파스타·우동·라면 등) 주 1회
23. **같은 메뉴는 7일 안에 두 번 금지**
    · 메뉴명이 완전히 같으면 같은 메뉴 (예: 다시마부각 → 다시마부각)
    · `생선이름+조림`은 부재료가 달라도 같은 메뉴 (삼치조림 = 삼치무조림, 고등어조림 = 고등어무조림)
    · **나물류(나물·무침·무생채)는 제외** — 규칙10에서 따로 간격을 봄
24. 누룽지탕 = 숭늉 (같은 메뉴, 보통 조식) — 주 2회까지 + 최소 3일 간격

> **'주 N회' 규칙은 달력상의 주가 아니라 연속 7일(21끼니) 이동 창으로 셉니다.**
> 그래서 일요일 조식 ↔ 다음주 월요일 석식처럼 주 경계를 넘는 중복도 잡힙니다.
> 단, 이걸 보려면 **두 주 파일을 함께 업로드**해야 합니다.

> 결과는 규칙 순서가 아니라 **날짜순**으로 정렬해 보여줍니다.
> '돈채'는 돼지, '우채'는 소로 인식합니다(채 썬 고기).

## 사용법
1. 주간 식단표 **엑셀(.xlsx)** 을 업로드합니다. 표 형태는:
   - 2행에 날짜가 가로로(07/06, 07/07 …)
   - A열에 `조 식` / `중 식` / `석 식`
   - 각 끼니 칸: 쌀밥/잡곡밥 → 국 → 반찬 여러 개 → 포기김치, 중식엔 죽
   - 쌀밥/잡곡밥·포기김치는 자동으로 검사에서 제외
2. **검사하기** 버튼을 누르면 규칙 위반과 '분류 실패 항목'이 나옵니다.
3. 여러 주를 함께 보려면 주간 식단표 파일을 **여러 개** 올리면 날짜순으로 이어 검사합니다.

## 참고
- 재료 분류는 키워드 사전으로 판단합니다. 사전에 없는 새 메뉴명은
  결과 하단 **분류 실패 항목**에 표시되니, 그 항목은 눈으로 한 번 더 확인하세요.
