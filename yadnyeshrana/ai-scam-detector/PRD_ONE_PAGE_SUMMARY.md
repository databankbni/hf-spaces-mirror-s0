# AI SCAM DETECTOR - ONE-PAGE SUMMARY

## What We're Building
AI-powered WhatsApp bot that detects scam messages in real-time for Indian users.

## The Problem
- 500M Indian WhatsApp users get 5-10 scams/day
- 3M Indians lose ₹2000-50K annually to fraud
- No existing solution that works on WhatsApp

## The Solution
**User workflow:**
```
User: Forwards suspicious message to bot
      ↓ (1-2 seconds)
Bot: Analyzes with Claude AI
      ↓ (2-3 seconds)
Bot: Returns risk assessment + recommendations
      ↓
User: Knows if it's a scam
```

## Key Features (MVP)
1. **Real-time scam detection** — <4 second response
2. **Risk classification** — HIGH/MEDIUM/LOW/SAFE with confidence score
3. **Action recommendations** — What to do if scam detected
4. **Freemium model** — 5 free checks/day, ₹199/month for unlimited
5. **Learning database** — Improves with every detection
