# RMT Diffusion Consistency Reproduction

This Space presents a CPU-only reproduction bundle for selected linear random-matrix claims from "A Random Matrix Perspective on the Consistency of Diffusion Models" (`iPjuUQbkfl`, arXiv `2602.02908v2`).

The evidence targets Silverstein noise renormalization, denoiser variance factorization/scaling, and sampling-map shrinkage/variance on deterministic synthetic spectra. It does not reproduce the paper's UNet/DiT image experiments because no official executable code artifact was found.
