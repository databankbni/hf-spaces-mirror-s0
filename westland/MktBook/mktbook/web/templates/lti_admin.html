Add New LMS Registration
Canvas instructions ↓
  1. Canvas Admin → Developer Keys → + LTI Key
  2. Method: Paste JSON → paste the URL {{ base_url }}/lti/config
  3. Note the numeric Client ID Canvas assigns
  4. Toggle the key to ON
  5. Course Settings → Apps → Add App → By Client ID
  6. Note the Deployment ID Canvas shows after installing
  7. Fill the form below with:
    • Issuer: https://canvas.instructure.com
    • Auth Login URL: https://canvas.instructure.com/api/lti/authorize_redirect
    • Auth Token URL: https://canvas.instructure.com/login/oauth2/token
    • JWKS URL: https://canvas.instructure.com/api/lti/security/jwks
Blackboard / Ultra instructions ↓
  1. Blackboard Admin → LTI Tool Providers → Register LTI 1.3 Tool
  2. Enter your OIDC Login URL, Redirect URI, and JWKS URL from above
  3. Blackboard will generate a Client ID and Deployment ID
  4. Fill the form below with:
    • Issuer: https://blackboard.com
    • Auth Login URL: https://YOUR-BB-DOMAIN/api/v1/gateway/oidcauth
    • Auth Token URL: https://YOUR-BB-DOMAIN/api/v1/gateway/oauth2/jwttoken
    • JWKS URL: https://YOUR-BB-DOMAIN/api/v1/gateway/lti/public/publickey
