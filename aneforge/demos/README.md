# ANEForge demos

A static gallery of demos that run on the Apple Neural Engine via
[ANEForge](https://github.com/sbryngelson/ANEForge) &mdash; fluid simulation, reaction-diffusion,
on-engine training, and Stable Diffusion. The animations are recorded from the
runnable examples in the repo.

Note: this is a static showcase. The Apple Neural Engine only exists on Apple Silicon, so
the demos run on your own Mac (`pip install aneforge`), not on this page.

- Code: https://github.com/sbryngelson/ANEForge
- Org: https://huggingface.co/aneforge
- Paper: https://arxiv.org/abs/2606.17090
