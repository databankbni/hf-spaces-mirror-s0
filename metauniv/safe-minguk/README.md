# 안전민국 — 국민과 기관이 함께 연습하는 AI 재난안전 훈련 플랫폼

제4회 재난안전데이터 활용 창업경진대회(행정안전부·NIA) 출품작.

주소를 입력하면 그 지역·기관에 맞춰 재난 시나리오가 생성되고, **행안부 표준매뉴얼·국민행동요령을
채점 기준**으로 대응 역량을 훈련·강평합니다. 국민 실시간 체험 모드와 기관 도상훈련(TTX) 모드를 제공합니다.

## 실연동 공공데이터
- 기상청 단기예보(기온·강수·풍속)·기상특보
- 행정안전부 재해 통계연보 3종(지역별 이재민·복구비·시도별 원인별 피해)
- 도로명주소(juso) 전국 인식

## 비밀키 (HF Settings → Variables and secrets)
- `DATA_GO_KR_KEY` — 공공데이터포털 인증키(기상청·통계연보). ⚠통계연보 계열(1741000)은 활용신청 시 허용 IP `*.*.*.*` 설정 필요.
- `JUSO_KEY` — 도로명주소 API 키(선택, 없으면 법정동 매칭으로 폴백).
- ⛔ `ANTHROPIC_API_KEY` 는 넣지 않습니다 — 규칙 엔진 폴백으로 0원 동작(공개 배포 과금 방지).

키가 없어도 규칙 엔진 + 샘플 데이터로 전 기능이 동작합니다(정직 라벨 표기).
