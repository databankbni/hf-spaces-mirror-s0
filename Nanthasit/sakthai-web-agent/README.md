# SakThai Web Agent 🌐

A Gradio Space demonstrating browser-automation and web-agent capabilities using SakThai models. Try tool-calling navigation, scraping, and structured interaction directly in the browser.

## What it does

- Uses browser-trained models from [SakThai Coder Browser](https://huggingface.co/datasets/Nanthasit/sakthai-coder-browser).
- Runs inference with [SakThai Coder 1.5B](https://huggingface.co/Nanthasit/sakthai-coder-1.5b) and [SakThai Context 7B Tools](https://huggingface.co/Nanthasit/sakthai-context-7b-tools).
- Demonstrates multi-step tool use: read page → call tool → submit action.

## Try it

Use the widget on this Space. No local setup required.
