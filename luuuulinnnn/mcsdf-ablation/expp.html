expP 设计稿 — observation-count noise map × warp memory

2026-08-01 · 设计规格，尚未训练 · 论文目标的一比一落地：观测累积 → 观测次数驱动的时空噪声图 → warp memory 初始化 → 先完成区域作为干净 attention 参照 · 骨架与配方全部继承 expF_sync（单变量可比）· 每个自由度都是带预注册预测的可扫参数，不是常数
一句话：goal 里"被观察越多 → 越低初始噪声 → 越早完成 → 引导未观测区"这条链， 现役最接近的实现是 expF_sync（用二值覆盖、无次数、cluster 池化）。expP 把三处不忠实的地方换掉： ① map 从覆盖换成真实观测次数 n_vis（已实现并双路几何验证）；② 质量信号（视角差 max_ang、光度分歧 photo）以 60×104 原生分辨率进条件通道， 替换 16×16 块状的 1-bit k；③ 训练主通道换成你要的"纯 warp + 噪声"（p_anchor 可扫至 1.0）。 同时尊重两条已测的红线：τ 地板 ≥ 0.5（memory 信息天花板 RMS(z_mem−x₀)=0.659），以及所有比较先过新尺子（种子噪声 0.1–0.3 dB 实测）。

Pipeline 总图

expP 全流程：A 缓存增广（逐像素可见性，原地追加不重建）→ B 共享噪声图（训练推理同族；τ_lo 三点扫直接裁决论文核心措辞）→ C 训练一步（sync 切片 + 内容无关上限替换 lift/patch_b2 + 纯 warp 锚点 + 55ch 原生分辨率通道）→ D 推理 50 步（SDEdit init + SYNC 下降 + 钉住即参照）。 底部三框：四个 delta 各配证伪实验 / 前置条件顺序 / 预注册预测。

Inference 要点

① τ 场：per-token 直接由 τ(n_vis) 给出，不再过 cluster-τ 的 128 簇 k-means（其 Xtok 质心在深度边界落在自由空间，且池化从未被证明有价值）。
② 初始化：SDEdit，x=(1−τ)·z_mem+τ·ε —— "保留 memory 信息"的实证主通道之一。未观测区 τ=1 纯噪声（goal 原文）。
③ 条件通道每步在场：[z_mem‖n_vis‖max_ang‖photo] @60×104 —— 让模型自己学"这块 memory 可信多少"，替代 1-bit 的 k 一刀切；同时解决 16×16 纹理粒度问题。
④ SYNC 下降：t_i(e)=τ_i−e，过零做 x0 投影后钉住（told=0.02）成为干净 attention 参照 —— goal 第 ⑤ 条的字面实现。 观测区（τ≈0.85）在 e≈0.85 落地，未观测区走满全程 → 完成次序 = 观测次序，全部在同一个联合扩散过程里。
⑤ 评分只认新尺子：≥20 held-out clips（剔除对齐残差异常 50–130× 的 00534f58）、mLPIPS 主指标、5 种子 bootstrap CI。

Training 要点

① t 场 = 推理日历同族：c~U(0,1)，t=clamp(τ−c, 0.02, 1)（expM 已验证此族可训）。
② 内容无关上限 f（35%）：t←max(t,f)，f~U(0,1) —— 一个动作替换 lift+patch_b2 两个旧补丁：给出 PF 式连续信息阶梯（补 n_vis 残余双峰性）， 并消灭旧 branch2 制造的"孤立干净 token 紧贴纯噪声"泄漏（训练 5.1% vs 推理 0 次）。
③ 锚点 = "纯 warp + 噪声"（你的提法）：covered 且 t≥0.3 时以 p_anchor 概率 x_t=(1−t)·z_mem+t·ε；p_anchor ∈ {0.4, 0.7, 1.0} 是主扫参二（1.0 即纯 warp 训练）。 回归目标恒指向真 x₀ —— "修正 splat"而非"复读 splat"，这条永不动。t≥0.3 的门保留：低 t 时推理状态是模型自己的投影结果而非 z_mem，在那里锚 z_mem 会训练一个推理从不访问的状态。
④ rehearsal 10% 保留（全局 t + 通道置零，保生成先验）。骨架/lr/步数与 expF_sync 完全一致。

前置条件（顺序不可换）与数据说明

1. 先修尺子 —— 实测同模型同采样器换种子抖 0.1–0.3 dB/clip；不修它，上面所有扫描都读不出来。
2. 缓存增广 —— n_vis/max_ang/photo 原地追加（augment_plucker 模式，~1s/clip × 1430）。几何已双路独立验证（Pearson 0.948、零系统偏移、遮挡阈值扫描结论稳定）。
3. 补 revisit 轨迹数据 —— 关键：在 DL3DV 单向前进轨迹上 n_vis≈coverage（秩冗余 0.86–0.92），"次数"这个卖点需要相机会回头的数据才能与 baseline 拉开。 仓库现成杠杆：dl3dv_cache.py 里未使用的 out-and-back 调度、RE10K/CARLA 缓存管线。预测：expP−expF_sync 的差距在 revisit 数据上大于前进数据。
本设计稿的每一条设计依据都来自本会话的已校验测量：τ_min 扫描（0.85>0.65>0.45）、信息天花板（RMS=0.659）、n_vis 诊断（连续但与覆盖高冗余）、 SYNC 同种子复赛（与 legacy 平局，机制无害）、PF 深挖（训练异质性是收益主体、上限即噪声地板）、16×16 粒度归因（日历架构强制、通道是实现选择）。
