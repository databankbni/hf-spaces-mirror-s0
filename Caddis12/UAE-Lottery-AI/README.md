# 🎲 UAE Lottery AI

Historical Analysis • Machine Learning • Smart Lottery Generator

This application analyzes historical lottery data using statistical analysis and machine learning techniques.

- 📊 Historical Analysis
- 🔥 Hot & Cold Number Detection
- 🤖 Machine Learning Predictions
