# ❤️ Heart Disease Predictor

This application predicts whether a patient is likely to develop heart disease within the next 10 years using a Machine Learning model trained on the Framingham Heart Study dataset.

## Features

- Heart disease prediction
- Prediction probability
- Gradio web interface
- Random Forest Machine Learning model

## Technologies Used

- Python
- Scikit-learn
- Gradio
- Pandas
- NumPy
